- 所有后端数据变更都经由 `bridge/events.ts` 的 `onNotification` / `onServerRequest` 进入 store，组件内不自行构造 UI 状态或轮询后端。
- store 采用单例可变状态 + `useSyncExternalStore` 订阅的模式（见 `appStore.ts`），对外只暴露纯函数式 action 与 snapshot 读取器。
- Rust 返回的对象字段名可能为 camelCase 或 snake_case，统一通过 `normalise*` 辅助函数（如 `normaliseSessions`、`normaliseProviders`、`normaliseSettings`）做双键兼容后再写入 store。
- 对 Tauri `invoke` 调用一律 `.catch(() => {})` 静默失败，因为 shell 状态是可选的，UI 不应因后端不可用而崩溃。
- 通过 Vite `resolve.alias` 将 `@` 指向 `app/`、`@protocol` 指向 `src/protocol/`，组件内部导入统一使用这些路径别名而非相对路径。
- 样式文件按职责拆分并在 `main.tsx` 集中 import（tokens/reset/shell/components/home/discovery/settings/dark 以及 approvals/modal/turn/settings-general），避免在组件内动态注入 CSS。
