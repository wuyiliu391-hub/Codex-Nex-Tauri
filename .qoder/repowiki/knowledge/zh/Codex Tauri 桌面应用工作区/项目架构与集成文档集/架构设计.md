本模块为纯文档目录，按职责划分为四个子域：
- 顶层 `ARCHITECTURE.md` 定义 L0–L4 分层（官方引擎协议 → Engine Host/Client → Shell API/Tauri command → React UI），并规定前端仅通过 L3 命令面与引擎交互的硬约束。
- `RUST_BACKEND.md` 详述 sidecar 启动流程、WS JSON-RPC 传输、三阶段握手、方法名表、审批请求响应、通知→Tauri 事件映射以及二进制解析与降级策略。
- `BROWSER-DEV.md` 描述在浏览器中绕过 Tauri 壳直接对接真实引擎的前端开发桥（vite alias + `/appserver` WS 代理 + localStorage shell-state 镜像）。
- `official-ui/` 保存官方 app-server 0.154.0 的方法清单（`.md` + `.json`）与界面截图；`uia/` 保存 UAT 遍历大纲与对应截图；`compose/change-notes/` 记录每次 compose 迭代的变更摘要。
- `LAYOUT.md` 与 `provider-setup.md` 分别说明仓库目录布局规则与自定义模型供应商配置步骤。
依赖方向单向：所有文档引用代码路径（如 `src-tauri/src/codex/*`、`frontend/app/devbridge/*`）作为事实来源，不反向被代码引用。
