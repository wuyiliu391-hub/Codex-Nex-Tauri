- 脚本以独立可执行形式存在，每个文件承担单一职责（构建、检查、UIA、测试），通过命令行参数或环境变量而非共享模块通信。
- PowerShell 脚本统一在顶部设置 `$ErrorActionPreference = "Stop"` 并使用 `Set-Location $PSScriptRoot\..` 将工作目录切回仓库根。
- Node 脚本采用 ESM 风格（`.mjs`），通过 `fileURLToPath(import.meta.url)` 推导仓库根路径，再基于相对路径访问 `frontend/`、`src-tauri/` 等子目录。
- 校验类脚本统一收集 failures/problems 数组，最后根据是否为空打印汇总信息并以非零退出码表示失败。
- UIA 相关脚本通过匹配进程名 `^(Codex|ChatGPT)$` 或 AppxPackage 安装路径来定位目标窗口，并对 UIA 属性访问包裹 try/catch 以容忍不可用控件。
