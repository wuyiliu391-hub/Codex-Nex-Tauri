该模块是纯脚本集合，按职责划分为四类：
- 构建与发布：`build.ps1` 调用 `cargo tauri build --no-default-features` 并依赖 `src-tauri/binaries` 中的官方 sidecar 二进制；`stage-dist.ps1` 将产物整理为 `dist/Codex-portable/`（含 `Codex.exe`、可选 `WebView2Loader.dll` 和 `binaries/` 侧车）。
- 前端静态检查：`check-frontend.mjs` 使用 Node 原生 `--check` 解析 `.ts`、对 `.tsx` 做括号平衡结构检查并验证 `@`/`@protocol` 别名导入；`verify-protocol-usage.mjs` 扫描 `frontend/app` 中形如 `namespace/method` 的字符串字面量，对照 `frontend/src/protocol/generated/protocol.json` 校验方法名并统计通知覆盖率；`verify-agent-a-hex.cjs` 限制 `frontend/src/styles` 中仅 token 文件可出现 `#hex`。
- 测试与迁移追踪：`test-adapter-protocol.mjs`、`test-sidebar-backend.mjs`、`dump-clean-stdio-logs.mjs`、`run-binary-stdio-capture.mjs`、`capture-window.ps1`、`diff-official-appserver-schema.mjs`、`migration-status.mjs`、`verify-notification-coverage.mjs` 等单用途校验脚本。
- UIA 自动化：`uia-dump.ps1` 通过 `System.Windows.Automation` 枚举窗口树并输出 JSON，`uia-watch.ps1` 轮询 Codex/ChatGPT 进程并在发现窗口时触发 dump，`uia-act.ps1`/`uia-compact.ps1`/`uia-wake-a11y.ps1` 提供点击/按键/唤醒辅助能力，`capture-official-pages.ps1` 编排这些工具自动截图生成 `docs/visual/` 文档图。
- 开发入口：`dev-browser.ps1` 检测端口后拉起官方 engine 并通过 `npm run dev:browser` 启动 Vite bridge 模式。
所有脚本均无外部运行时依赖（除 PowerShell/.NET UIAutomation 与 Node 标准库），彼此通过命令行参数或环境变量协作，不共享模块。
