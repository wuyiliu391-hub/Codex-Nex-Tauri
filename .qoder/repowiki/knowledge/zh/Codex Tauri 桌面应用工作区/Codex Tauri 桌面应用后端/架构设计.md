以 `src/main.rs` 为 Windows GUI 入口，调用 `codex_tauri_lib::run()` 进入由 `lib.rs`、`state.rs`、`menu.rs` 组成的运行时：先初始化 tracing、持久化状态（tauri-plugin-store）、系统托盘菜单，再按功能域在 `commands/` 下注册 Tauri 命令（app_state、calendar、cinema、connectors、engine、fs、market、pets、scheduled、settings），并通过 `codex/` 子模块（adapter/client/events/protocol/sidecar）管理 codex-app-server sidecar 的生命周期与 WebSocket 事件转发；`capabilities/default.json` 声明插件权限，`tauri.conf.json` + `build.rs` 完成打包配置，最终产物为可独立运行的 Windows 二进制（`binaries/`）。
