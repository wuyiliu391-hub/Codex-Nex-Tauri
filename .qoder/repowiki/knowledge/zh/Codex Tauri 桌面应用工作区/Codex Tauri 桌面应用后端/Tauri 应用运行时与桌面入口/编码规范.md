- IPC 命令统一在 `lib.rs` 的 `tauri::generate_handler!` 宏中以 `module::function` 形式集中注册，按功能域（app_state/settings/pets/calendar/cinema/connectors/fs/scheduled/market/engine）分组排列。
- UI 层状态模型全部派生 `Serialize + Deserialize + Clone + Default`，并通过 `#[serde(default)]` 保证旧版本配置文件向后兼容。
- `AppState` 的内存态使用 `Mutex<InnerState>` 包裹，对外暴露 `snapshot()` 返回不可变快照，写操作通过 `save()` 原子写入临时文件再 `rename` 避免部分写入。
- 菜单项通过 `MenuItem::with_id(app, id, label, enabled, Some("快捷键"))` 构造，action id 以小写连字符命名（如 `new-task`、`toggle-sidebar`），并由 `on_menu_event` 统一以 `menu` 事件名 + id 字符串转发给前端。
- Provider 密钥不直接写入配置文件，而是通过 `provider_env_key` 生成形如 `CODEX_PROVIDER_<ID>_API_KEY` 的环境变量名，仅在 `provider_secrets` 中保存明文并在启动 sidecar 时注入。
