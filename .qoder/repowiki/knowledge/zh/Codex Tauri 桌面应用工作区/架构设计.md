根 `Cargo.toml` 声明 `[workspace] members = ["src-tauri"]`，统一版本（0.154.0）、edition 2024 与共享依赖表，使 `rust_backend`（Tauri 壳）作为唯一 crate 被引用；`frontend_app` 通过 Vite/Tauri CLI 在构建时注入静态资源并由 `src-tauri` 的 sidecar 启动 `codex-app-server-*.exe`，形成 React UI → Tauri Shell API → app-server JSON-RPC → 官方引擎的分层通信链；`docs` 集中记录该分层契约与方法清单，`scripts` 提供 Windows 打包、协议/样式校验与浏览器开发模式等跨子模块的一体化流程。所有子模块围绕“预编译 sidecar + Tauri IPC”这一边界协作，不直接共享源码。
