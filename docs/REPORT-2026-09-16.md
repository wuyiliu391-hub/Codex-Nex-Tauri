## 3. 供应商配置 saga（T26–T29）

用户提供：`https://rabbitapi.online/v1` + Key（51 字符）+ 模型（先 `-exp` 后 `deepseek-v4-flash`）。Key 只进环境变量 `RABBIT_API_KEY`（用户级），不落 TOML。

### 3.1 踩坑链

1. **野 key 回落**：`model_provider` append 到文件尾 `[projects]` 表内 → 静默回落 openai → 桌面 401（用的 `auth.json` 10 字符模拟串打 `api.openai.com`）、CLI 超时。**修复**：顶层 `model = …` 下一行。教训：改 TOML 必须意识到表作用域。
2. **`-exp` 模型推理端 404**（path 级）：`…/v1/responses` 404；枚举发现网关 chat/completions 同 404、`/v1/messages` 404（畸形包体 500，不稳定）、仅 `/v1/models`=200。换 `deepseek-v4-flash` 即通。
3. **web_search 不兼容**：flash 报 `does not support native web search` → 设置→配置→网页搜索→已禁用（写 `web_search = "disabled"`）。
4. **wire 别无选择**：0.154 明确移除 `wire_api="chat"`（`is no longer supported`），responses 是唯一 wire。
5. **E2E 金标准**：CLI `provider: rabbit` + 返回 `ROUTE_OK`（约 4k tokens，含一次重连抖动属正常）。

### 3.2 最终可用配置（`config.toml` 头部）

```toml
model = "deepseek-v4-flash"
model_provider = "rabbit"
model_reasoning_effort = "xhigh"
web_search = "disabled"

[model_providers.rabbit]
name = "RabbitAPI"
base_url = "https://rabbitapi.online/v1"
env_key = "RABBIT_API_KEY"
wire_api = "responses"
requires_openai_auth = false
```

改完重启 App 生效（配置启动时加载）。原文件已备份 `config.toml.bak-2026-09-16-uia`。**Key 在聊天记录裸奔过，务必去控制台轮换。**

## 5. 工具链与经验

### 5.1 脚本（`scripts/`，远端）

- `uia-act.ps1`：动词 Expand/Collapse/Invoke/Toggle/SetValue/Focus/**Click（真鼠标）**；`-Keys` SendKeys；`-OutlineMatch/-OutlineMatchCt` 裁剪；`-DumpTag` 落盘；`-Quiet`（单行 qsum）；**`-NoFg`**（跳过前台化，子模态对话框按键必备）。
- `uia-dump.ps1`：ControlViewWalker 递归，8000 节点/100 秒预算；自动恢复最小化窗口；可自启动 App。
- `uia-compact.ps1`：JSS 解析 JSON（PS5.1 无 `ConvertFrom-Json -Depth`），内容区提取，跳 Image/匿名 Pane，保留 tog/exp/val/OFF/DIS/SEL/aid。
- `uia-wake-a11y.ps1 -Mode Get/Set/Restore`：SPI 屏幕阅读器标志（遍历需=1，收尾 Restore=0；注：恢复后 dump 照常工作，renderer a11y 已初始化）。

### 5.2 修过的 Bug

- `-Ct` 恒真：局部 `$ct` 与参数 `$Ct` 大小写不敏感冲突 → 改名 `$ctName`。
- `ConvertFrom-Json -Depth` 不存在（PS5.1）→ JSS + MaxJsonLength 60MB（吃 3.7MB 键盘页）。
- 单 batch 多全量 outline 截断 → 一批最多 1 个全量，其余 qsum/match。

### 5.3 原生对话框打法（`Select Project Root`）
